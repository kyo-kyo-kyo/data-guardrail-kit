# Security Policy

## Supported Versions

Security fixes are provided for the latest released version.

## Reporting A Vulnerability

Please report suspected vulnerabilities privately by opening a GitHub security advisory when the repository is public.

Do not include private datasets, credentials, customer information, or production files in public issues.

## Data Handling

Data Guardrail Kit runs locally and does not transmit input files over the network.

Users are responsible for reviewing CSV files, schemas, and generated reports before sharing them publicly.

## Scope

Security reports are in scope when they involve:

- unintended file disclosure
- unsafe path handling
- dependency vulnerabilities
- command execution risks
- incorrect handling of sensitive local files

Questions about audit rule design or false positives should be opened as regular issues.
