# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple version history until a public release process is established.

## [0.1.0] - 2026-06-01

### Added

- CSV encoding detection.
- CSV delimiter detection.
- Required column checks.
- Basic type checks for string, integer, number, boolean, and date values.
- Duplicate column detection.
- Missing-rate checks.
- Duplicate ID checks.
- Feature-name audit for configurable leakage tokens.
- Markdown report generation.
- CLI entry point: `data-guardrail-kit audit`.
- Synthetic examples and unit tests.
- GitHub Actions CI workflow.
- Contribution and security documentation.
